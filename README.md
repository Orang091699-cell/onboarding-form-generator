# 入职确认单生成器

这是一个纯静态网页应用。Excel 解析和 Word 生成均在浏览器本地完成，花名册不会上传到服务器。部署到任意静态网站服务后，可以在任何电脑上通过网址使用。

使用流程：

1. 上传导出的 `.xlsx` 花名册。
2. 选择日期依据、开始日期、结束日期、工号前缀和人员类型，并填写 HR 确认人；日期区间包含起止当天。
3. 检查按工号排序的人员名单。
4. 点击“生成并下载确认单”。每位员工的合同编号和页底日期使用其自己的实际日期。

生成器使用目录中的 `template.docx`。

## 本机预览

双击 `启动生成器.command`。

## 发布到公网

可直接将整个目录部署到 Cloudflare Pages、Netlify、GitHub Pages 或任意静态服务器。无需 Python、数据库或服务器函数。
